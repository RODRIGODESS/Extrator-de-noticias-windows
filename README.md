# Extrator de Matérias Ubuntu Portable v1.25.10

Versão Ubuntu espelhada da versão Windows V1.25.10, mantendo o mesmo layout, funções, motor e correções de extração, com adaptações apenas para Linux/Ubuntu.

## Recursos
- Layout moderno igual ao Windows
- Conteúdo editável antes de copiar
- Histórico e último TXT
- Pasta Downloads/ExtratorMaterias
- Proxy preservado
- Build AppImage
- Publicação automática em GitHub Releases

## GitHub Actions
O workflow `.github/workflows/build-ubuntu.yml` compila e publica automaticamente a versão final em Releases ao enviar o projeto para a branch `main` ou ao executar manualmente o workflow.
