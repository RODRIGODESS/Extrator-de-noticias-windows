# Extrator de Matérias Android v1.25.1

Projeto Android com layout moderno, conteúdo editável antes de copiar e conexão direta sem proxy.

## GitHub Actions
O workflow `.github/workflows/build-android.yml` compila o APK e publica automaticamente o arquivo final em GitHub Releases quando houver push na branch `main` ou execução manual.

## Estrutura
O projeto Android está dentro da pasta `android/`.
